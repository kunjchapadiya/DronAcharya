# 🚁 Drone Spraying Service - Admin Panel & Pilot Dashboard

This project is a web-based **Drone Spraying Management System** designed to streamline agricultural spraying operations. It includes an **Admin Panel** for service management and a **Pilot Dashboard** for monitoring drone activities, flight logs, maintenance alerts, and spray coverage.

---

## 🚀 Features

### Admin Panel
- User and pilot management
- Service request handling
- Reports and analytics dashboard

### Pilot Dashboard
- Flight logs with timestamps
- Spray coverage reports
- Maintenance alerts and schedules

---

## 🛠 Tech Stack

**Frontend:**
- HTML5, CSS3, JavaScript
- Bootstrap / TailwindCSS (optional)

**Backend:**
- PHP (Core PHP or Laravel)
